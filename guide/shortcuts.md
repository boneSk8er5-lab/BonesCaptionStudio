# Keyboard shortcuts

| Keys | What it does |
|---|---|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | New / open / save project |
| `Ctrl+Shift+S` | Save project as |
| `Ctrl+I` | Import a video |
| `Ctrl+E` | Export a complete video |
| `F5` | Generate captions |
| `F6` | Detect voices |
| `Space` | Play / pause the preview |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+F` | Search the transcript |
| `Delete` | Hide / show the selected lines or words |
| `Shift+Delete` | Delete the selected words for good |
| `1` to `9` | Give the selected lines that voice |
| `0` | Take the voice off the selected lines |
| Double-click | Edit a line or word |
| Right-click | More transcript options |
| `F1` | Open this guide |
| `Ctrl+F1` | Show the shortcuts list |
| `Ctrl+Q` | Close the app |

> `1` to `9`, `0` and `Delete` change the lines selected in the Transcript Editor, so select some lines first.
